# LangChain Tutorial with Ollama

This project demonstrates a simple LangChain app that sends a prompt to a local Ollama model and prints the generated response.

The app in [src/langchain_tutorial/main.py](src/langchain_tutorial/main.py) creates a prompt template, injects a short biography, and asks the model to return:

1. a short summary
2. two interesting facts about the person

It uses the local model `llama3.2` through `ChatOllama`.

## What this project does

- Creates a `PromptTemplate`
- Connects it to `ChatOllama`
- Calls the model with a sample biography
- Prints the final text output

## Requirements

- Python 3.11+
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- [Ollama](https://ollama.com/) installed and running locally

## Setup

From the repository root, install dependencies:

```powershell
uv sync
```

Start Ollama if it is not already running, then pull the model used by the project:

```powershell
ollama pull llama3.2
```

If Ollama is not running, start it before launching the app:

```powershell
ollama serve
```

## Run the app

Run the script directly:

```powershell
uv run python -m langchain_tutorial.main
```

Or use the project entry point:

```powershell
uv run langchain-tutorial
```

## Expected behavior

The program will print a response similar to a summary of Elon Musk and two facts about him, generated by the local model.

If the model or Ollama server is unavailable, the script prints a helpful error message and tells you to run:

```powershell
ollama pull llama3.2
```
